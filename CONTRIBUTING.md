# Contributing to dsh-ssh-remote

Thanks for your interest in contributing!

## How to Contribute

1. **Fork the repository** and create a branch from `main`
2. **Make your changes** – keep them focused on a single issue
3. **Test your changes** – run `node -c lib/index.js` and `node -c lib/client.js` to verify syntax
4. **Submit a pull request** with a clear description of what you changed and why

## Development Setup

```bash
git clone https://github.com/your-username/dsh-ssh-remote.git
cd dsh-ssh-remote
npm install --no-save
```

## Code Style

- 2-space indentation
- LF line endings
- UTF-8 encoding
- No trailing whitespace
- Follow the existing code patterns in `lib/`
